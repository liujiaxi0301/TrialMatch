# Manual error review categories

Apply these only after inspecting the original response, source criterion and patient facts. Validation warnings identify review targets; they are not automatically confirmed model errors. Multiple categories may apply.

| Code | What to inspect |
| --- | --- |
| SOURCE_INCOMPLETE | Retrieved trial source is incomplete or a page shell/snippet. |
| CONDITION_OMISSION | A source clause is missing or its substantive text was not assessed. |
| EVIDENCE_OMISSION | Relevant available patient evidence was missed. |
| NEGATION | A negation or exclusion's polarity was misread. |
| TEMPORAL | Dates, duration, recency, or unknown visit anchors were misinterpreted. |
| NUMERIC_OR_UNIT | A threshold, range, comparator or unit was misinterpreted. |
| MEDICATION_EVIDENCE | Orders, dispensing, administration, stable use or adherence were conflated. |
| UNSUPPORTED_INFERENCE | An assertion or threshold has no support in supplied evidence. |
| WRONG_CITATION | A fact ID is invalid or the cited fact does not support the assertion. |
| UNKNOWN_HANDLING | Missing information was turned into a definite positive/negative, or supported evidence was left unknown. |
| CODE_INTERPRETATION | A code system/code was misread or display text overrode the coded concept. |
| FORMAT | Requested response format was not followed. |

Keep retrieval completeness, label correctness, evidence support and reasoning quality separate. Matching status labels alone do not establish correct reasoning. An exclusion marked MET means the exclusion applies.

Record manual error judgments in `results/error_review.csv` (run_id, model_criterion_id, source_criterion_id, error_types, reasoning, reviewer, needs_review). This is an editable review file and is not regenerated by the response recorder. `runs_A/B.csv` and `model_results_A/B.csv` are derived exports; do not edit them. Scores are intentionally not implemented during recovery.
